THREAT MODEL
------------

Threats Mitigated by Network Isolation:

1. ✓ Data exfiltration to external servers
2. ✓ Downloading malicious code from internet
3. ✓ DNS-based data exfiltration
4. ✓ Communication with C&C servers
5. ✓ Lateral movement to other containers
6. ✓ Port scanning external networks
7. ✓ DDoS participation

Allowed Operations:

1. ✓ Code execution in worker
2. ✓ Communication with controller via exposed port
3. ✓ File I/O within tmpfs
4. ✓ Using pre-installed packages
